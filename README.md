## RackNerd 是什么：一句话说清

RackNerd 是一家美国基础设施服务商，2019 年成立，主做 KVM 虚拟化的便宜 VPS，外加独立服务器、托管和共享主机。它的核心卖点很直白——价格压得低，机房分布广，配置不缩水。所有 VPS 都是 KVM 虚拟化，给完整 root 权限，1Gbps 端口，RAID-10 SSD 存储，开机即用。

## 性能与稳定性实测：别期待旗舰，但够用

我自己手上跑的是它家 4GB 那档机器，机房选在洛杉矶。先把实测数据摆出来：

- **CPU 单核跑分**：Geekbench 6 单核大概在 1100-1300 之间，多核 3500 上下。这个成绩对年付几十刀的机器来说算中规中矩，比不上动辄两三千的旗舰，但日常建站、跑代理、搭面板完全够。
- **磁盘 IO**：持续读写稳定在 400-600MB/s，是正经 SSD 而不是拿 HDD 凑数。RAID-10 阵列下随机 IO 也不拉胯。
- **网络带宽**：标称 1Gbps，实测能跑到 800Mbps 以上，国外节点测速基本能吃满。国内访问走优化线路，晚高峰会打折，但日常够用。
- **稳定性**：用了一年多，真正宕机只有一次，是凌晨维护，提前有邮件通知。中途偶尔有几分钟网络抖动，不影响服务运行。

讲真，这个价位你跑去要 Linode 那种 99.99% SLA 不现实。但 RackNerd 的稳定性在同档位里属于上游，比那些名字都没听过的商家靠谱得多。

RackNerd 在北美、欧洲、亚洲有 20 个机房，国内用户最关心的就是延迟。直接给结论：

我自己测下来，洛杉矶 DC-02 是综合体验最好的，开机快、线路稳、晚高峰降幅小。圣何塞是备选。

## 几个我踩过的坑

顺便提一嘴几个新手容易忽略的点：

一是**别只看 CPU 核数**。RackNerd 的 vCPU 是共享核心，4 核不一定比别家 2 核强多少。真正决定体验的是磁盘 IO 和网络稳定性，这两点 RackNerd 表现都在水准之上。

二是**特惠套餐抢完就没了**。新年特惠、黑五特惠这类活动都是限量发售，卖完下架。我去年黑五就因为犹豫错过 8GB 那档，等了一年才等到下一个同档活动。看到合适的配置别犹豫太久。

三是**控制面板是 SolusVM 不是 WHMCS**。下单在 WHMCS，管理机器在 SolusVM，两个面板分开。第一次用的人会找不到入口，登录后点 "Services" → "My Services" → 进对应机器就能看到 SolusVM 链接。
